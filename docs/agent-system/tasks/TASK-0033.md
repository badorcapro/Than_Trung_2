# TASK-0033: Gatekeeper Upgrade Nhịp 0.2b (.gd Line Budget & Baseline Exemptions)

## 1. Context & Rationale
Under Stage 4 (Chặng 4) of Thần Trùng 2 Fan-Game development, we enter the deep refactoring and reconstruction of the Godot codebase (`Than_Tham_Nua_Voi_Godot/`).
Before touching any GDScript file, Gatekeeper Nhịp 0.2b must be upgraded:
- Previously, `line_budget.include_extensions` only monitored general languages (`.py`, `.cs`, `.ts`, etc.). GDScript (`.gd`) files were unmonitored.
- The existing Godot codebase contains 13 legacy "God-files" (> 800 LOC) created prior to AI-AGENTS governance.
- Adding `.gd` without baseline exemptions would immediately cause whole-repo line budget checks to fail.
- Adding `baseline_exemptions` freezes these 13 files from line budget blocking while keeping them under `check_diff_guard.py` to prevent code truncation or placeholder insertion. As we refactor each module (`CaseGenerator.gd`, `SuspectCardController.gd`, etc.), they will be removed from `baseline_exemptions`.

## 2. Technical Scope & Implementation Plan
1. `docs/agent-system/project-config.json`:
   - Add `".gd"` to `line_budget.include_extensions`.
   - Add role mapping entries for Godot scripts:
     - `Than_Tham_Nua_Voi_Godot/scripts/presentation/**` -> `ui_component`
     - `Than_Tham_Nua_Voi_Godot/tests/**` -> `test`
     - `Than_Tham_Nua_Voi_Godot/scripts/tools/**` -> `test`
   - Add `baseline_exemptions` with all 13 legacy God-files.
2. `scripts/agent/config_models.py`:
   - Add `baseline_exemptions: List[str] = Field(default_factory=list)` to `LineBudgetConfig`.
3. `scripts/agent/check_line_budget.py`:
   - Check `baseline_exemptions` in `check_line_budget`: if file is in `baseline_exemptions`, classify tier as `baseline_exempt` or treat as exempt, avoiding `ERR_LBUD_HARD_EXCEEDED` / `ERR_LBUD_REVIEW_REQUIRED`.
   - Ensure cohesion notes check ignores baseline exempt files.
4. `tests/test_check_line_budget.py`:
   - Unit tests validating `.gd` extension inclusion, role resolution, baseline exemptions handling, and CLI execution.
