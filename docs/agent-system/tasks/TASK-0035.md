# TASK-0035: Pilot DO-05 — Detective Board & Suspect Card Clean Rebuild

## 1. Context & Rationale
Under field problem report `docs/agent-system/problems/Tua_game_nay_dang_co_van_de.txt` (DO-05) and user visual specifications:
1. Suspect Card Visual Inversion: Suspect cards suffered from unreadable 5px micro-text shrinking, broken anchor offsets (`anchor_right = 1.42` clipping out of bounds), and an inappropriate ornate parchment hole frame.
2. User Visual Requirement: The user requested a strict 2-state visual parity:
   - State 1 (Before investigation): Closed door card (`Door_01..09`), clear large room number in white.
   - State 2 (Investigated/Open): Clean rectangular Polaroid card (`card_outer_frame.png` 230x260), dark square for role icon + suspect number, clear role title, readable statement ($\ge 13$px), pushpin, and red dead stamp marker.
3. Detective Board Canvas: Fixed 1920x1080 canvas pixel-snap with interactive Catenary2D yarn strings and tactile audio feedback.

## 2. Technical Scope
- Selective import of original props (`assets/ui/dupery_props/`) and audio samples (`assets/audio/sfx/`).
- Rebuild `SuspectCard.tscn` & `SuspectCardController.gd`.
- Rebuild `VSCaseMain.tscn` & `VSCaseMainController.gd` with modular `CatenaryYarnLayer.gd`.
- Author `tests/test_detective_board_presentation.py`.
- Run Subagent Peer-Audit and verify.
