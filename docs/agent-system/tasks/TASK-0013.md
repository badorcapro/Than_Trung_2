# TASK-0013: Extract and Catalog Dupery Project Settings

## Bối Cảnh & Mục Tiêu Kỹ Thuật
Trong kiến trúc game Unity, toàn bộ cấu hình gốc của dự án (Project Settings) được lưu trữ nhị phân bên trong tệp `globalgamemanagers`. Để phục vụ cho việc đối chiếu và tái lập kiến trúc trên Godot 4 trong các chặng tiếp theo, `TASK-0013` bóc tách toàn diện 11 Project Settings managers:
1. `BuildSettings`: Thứ tự 12 scene trong bản build (`level0`..`level11`).
2. `TagManager`: Danh sách tags, collision layers, và sorting layers (`Default`, `Cursor`).
3. `Physics2DSettings`: Gravity, material mặc định, velocity/position iterations.
4. `QualitySettings`: Cấu hình đồ họa, shadow distance, v-sync, texture quality.
5. `GraphicsSettings`: Tier settings, shader stripping, và `m_AlwaysIncludedShaders`.
6. `TimeManager`: Fixed timestep (0.02s), maximum timestep, time scale.
7. `InputManager`: 100% cấu hình trục điều khiển (`m_Axes`), phím bấm và joystick.
8. `PlayerSettings`: Tên game, tên công ty, độ phân giải mặc định (1920x1080), fullscreen mode.
9. `AudioManager`: Volume master, speaker mode, DSP buffer size, sample rate.
10. `PhysicsManager`: 3D gravity và collision matrix.
11. `NavMeshProjectSettings`: Agent types và area costs.

## Tiêu Chuẩn Hoàn Thành
- 11/11 file JSON cấu hình độc lập được lưu tại `docs/agent-system/evidence/dupery/project_settings/<ManagerName>.json`.
- File tổng hợp `project_settings_summary.json` cung cấp bảng tra cứu nhanh, đặc biệt là bảng ánh xạ 12 scene build index sang file `level*`.
- Script `scripts/agent/dupery_project_settings.py` có cờ `--verify` và `--stats` tuân thủ nghiêm ngặt ADR-0010 Line Budget ($< 300$ LOC).
