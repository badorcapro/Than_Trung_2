# TASK-0016: Extract Sprite, Texture2D, and Font Vault with SHA-256 Manifest

## Bối Cảnh & Mục Tiêu Kỹ Thuật
Theo kết quả khảo nghiệm số lượng tại mục P2 trong Master Plan (`PLAN-CHANG-3-DUPERY-RECONSTRUCTION.md`), game *Dupery* chứa:
- **879 Sprites** (chứa hình ảnh thẻ bài, icon vai trò, quirks, giao diện UI, cắt từ Texture atlas).
- **752 Texture2D** (các tấm atlas lớn và kết cấu đồ họa).
- **10 Fonts** (các phông chữ TTF/OTF đa ngôn ngữ bao gồm SourceHanSans, NotoSansCJK, Veteran Typewriter, DOS VGA).

`TASK-0016` thực hiện:
1. Xây dựng module điều phối `scripts/agent/extract_dupery_vault.py` tự động quét toàn bộ các file `.assets` và trích xuất siêu dữ liệu đồ họa chi tiết:
   - Tọa độ cắt ảnh Atlas: `rect` (`x`, `y`, `width`, `height`).
   - Tâm xoay/đặt điểm: `pivot` (`x`, `y`).
   - Biên co dãn Nine-Slice: `border` (`left`, `bottom`, `right`, `top`).
   - Tỷ lệ hiển thị đơn vị: `pixels_per_unit`.
   - Băm mật mã toán học: `sha256` của dữ liệu ảnh PNG/font binary.
2. Xuất bản `docs/agent-system/evidence/dupery/vault/dupery_vault_manifest.json` làm chứng từ bất biến (cryptographic single source of truth).
3. Hỗ trợ lệnh bung 1 bước (`--extract-all` hoặc `--vault-dir`) để tái tạo 100% kho tài nguyên hình ảnh ra đĩa khi cần tái thiết sang Godot 4.
4. Cập nhật `.gitignore` và `scripts/agent/check_scope.py` để miễn trừ vùng nhớ đệm nhị phân lớn, giữ cho repo Git luôn gọn gàng và tốc độ cao.
