# TASK-0020: Execute Runtime Probe Spike and Determine Go/No-Go Feasibility

## Bối Cảnh & Mục Tiêu Kỹ Thuật
Kế hoạch Chặng 3 v2.0 (`PLAN-CHANG-3-DUPERY-RECONSTRUCTION.md`) đặt ra yêu cầu thẩm định tính khả thi của việc can thiệp runtime (**Runtime Probe Spike**) vào tiến trình đang chạy của *Dupery* (Unity Mono x86 trên Windows 64-bit).
Mục đích cốt lõi của việc can thiệp runtime là:
1. Ghi nhận thứ tự gọi hàm và đường cong tween/easing thực tế.
2. Kiểm chứng tính tất định của thuật toán sinh vụ án theo hạt giống ngẫu nhiên (`seed -> CaseCreation`).

Theo chỉ đạo của người dùng: Thử nghiệm phương án can thiệp runtime (BepInEx 5.x x86). Nếu gặp rào cản kỹ thuật hoặc chất lượng kém, kích hoạt ngay phương án dự phòng chuẩn kiến trúc: **NO-GO** và áp dụng **Offline Logic Verification** (chứng minh tính tất định và cấu trúc vụ án trực tiếp từ mã nguồn C# decompiled) kết hợp với **Reference Capture**.

## Nhiệm Vụ Cụ Thể
1. **Thực Nghiệm Thử Nghiệm BepInEx 5.x x86**:
   - Thẩm định tương thích giữa BepInEx x86 và `Dupery.exe` (MonoBleedingEdge x86).
   - Kiểm tra hành vi khởi động của game khi có wrapper hook: kiểm tra phát sinh lỗi crash, xung đột Steam API hoặc Unity Crash Handler.
   - Dọn dẹp sạch sẽ 100% các tệp thí nghiệm khỏi thư mục game Steam (`winhttp.dll`, `doorstop_config.ini`, `BepInEx/`).
2. **Thẩm Định Ngoại Vi (Offline Logic Verification)**:
   - Phân tích và kiểm chứng thuật toán sinh ngẫu nhiên `SeedRandom` và cấu trúc `CaseFile` từ C# decompile (`Assembly-CSharp/CaseCreation/`).
   - Lập bảng mô hình hóa tham số easing từ `GRGLib.Easing`.
3. **Báo Cáo Quyết Định Kỹ Thuật (Spike Report)**:
   - Xuất bản `runtime_probe_spike_report.md` và `runtime_probe_decision.json`.
   - Cung cấp CLI `dupery_runtime_probe.py` có cờ `--verify` và `--stats`.
