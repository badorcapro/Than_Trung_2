# TASK-0011: Build Dupery Code Catalog and Obligation Ledger (Depth L1-L4)

## Bối Cảnh & Mục Tiêu Kỹ Thuật
Sau khi hoàn thành `TASK-0010` (decompile 1.463 file .cs), `TASK-0011` thiết lập **Sổ cái Nghĩa vụ Tái thiết (Reconstruction Obligation Ledger)** và Danh mục Mã nguồn (`dupery_code_catalog.json`) nhằm thực thi cam kết **chống bỏ sót 100% (DEC-20, DEC-21)**.

Mỗi kiểu dữ liệu (Class, Struct, Interface, Enum, Delegate) sẽ được phân loại:
1. `tier`: Tier 1 (Gameplay / Domain lõi của Dupery) vs Tier 2 (Engine Framework, Localisation, Audio Bridge, Node Graph).
2. `vong`: V1–V8 theo đúng bảng phân bổ Spec Chặng 3 v2.0 hoặc các phân hệ framework.
3. `depth`: Thang 4 cấp độ sâu per `DEC-21`:
   - `L1` (cataloged): Tọa độ file .cs, metadata, namespace, base class.
   - `L2` (summarized): Tóm tắt vai trò, API public, state đọc/ghi.
   - `L3` (algorithm_extracted): Thuật toán, công thức, hằng số toán học, coroutine logic.
   - `L4` (ported_and_compared): Triển khai trên Godot và kiểm thử đối chiếu (dành cho Chặng 4+).
4. `is_nested` & `nested_of`: Ghi nhận chính xác kiểu lồng nhau để giải quyết dứt điểm sai lệch số liệu P6.

## Tiêu Chuẩn Hoàn Thành
- `unaccounted == 0`: Không có bất kỳ kiểu dữ liệu nào bị bỏ sót ngoài sổ cái.
- CLI `dupery_code_indexer.py` có cờ `--verify` và `--stats` đạt chuẩn ADR-0010 ($<300$ LOC).
