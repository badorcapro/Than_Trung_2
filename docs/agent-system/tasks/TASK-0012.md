# TASK-0012: Validate TypeTree Gate (DEC-22) for MonoBehaviour & XNode Decoding

## Bối Cảnh & Mục Tiêu Kỹ Thuật
Theo quyết định kiến trúc **`DEC-22` (TypeTree Gate)** trong Master Plan Chặng 3 v2.0 (`PLAN-CHANG-3-DUPERY-RECONSTRUCTION.md`), `TASK-0012` là chốt chặn then chốt (blocking gate) nhằm kiểm định khả năng giải mã dữ liệu `MonoBehaviour` (Inspector, ScriptableObjects, và Node Graphs) từ các file asset của tựa game gốc *Dupery* (Unity 2022.3.62f3).

## Thiết Kế Kỹ Thuật & Bài Học Thực Nghiệm
1. **Lựa chọn Phương án 1 (DEC-22)**: Sử dụng `UnityPy 1.25.4` kết hợp `TypeTreeGeneratorAPI 0.0.10` nạp metadata từ `Dupery_Data/Managed/`.
2. **Bộ lọc tệp nghiêm ngặt**: Chỉ nạp các file đuôi `.assets` và các file scene `level*`. Tuyệt đối loại trừ các file stream nhị phân thô (`.resS`, `.resource`, `.assets.resS`) để tránh tràn RAM và treo tiến trình.
3. **Tối ưu hóa Pre-load Script**: Luôn nạp trước `globalgamemanagers.assets` trong cùng `UnityPy.Environment` để ánh xạ `m_Script` tức thì (~0.0001s/object) thay vì mở lại từ đĩa.
4. **Xử lý chuyên biệt cho XNode (P7)**: Nhận diện các class `Nodes.*` kế thừa `XNode.Node` có `NodePortDictionary` (custom serialized dictionary). Ghi nhận toàn bộ 1.179 instances của XNode vào `typetree_failures.json` với lý do kỹ thuật chi tiết, đồng thời bảo đảm 100% các class gameplay, UI, visual, và ScriptableObjects (`Quirks`, `CaseFile`) được giải mã toàn vẹn.
5. **Tuân thủ Chuẩn ADR-0010**: Module điều phối `dupery_typetree_decoder.py` phải $< 300$ LOC, không cheat code.
