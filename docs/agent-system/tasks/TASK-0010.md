# TASK-0010: Decompile 4 Assemblies & Lập Build/Decompile Manifest

## Bối Cảnh & Mục Tiêu Kỹ Thuật
Đây là task mở màn của **Tầng A (Nền tảng)** trong Kế hoạch Chặng 3 (v2.0). Để phục vụ cho việc giải phẫu 100% logic tựa game gốc *Dupery*, toàn bộ mã CIL (.NET Mono) trong 4 assemblies chính và bridge assembly cần được giải mã sang C# nguyên bản:
1. `Assembly-CSharp.dll`: 890 top-level types, 27 nested types (Gameplay, CaseCreation, Visual, Leads, Save, Nodes).
2. `gildedrunegames.grglib.dll`: 98 top-level types, 2 nested types (Tweening, UI Line, Coroutines, Math, Camera).
3. `gildedrunegames.grglocalisation.dll`: 4 top-level types (Localisation system & dictionary).
4. `XNode.dll`: 9 top-level types, 12 nested types (Node graph framework).
5. `FMODUnity.dll`: 50+ types (FMOD audio bridge & events).

## Yêu Cầu Thiết Kế CLI `dupery_decompile.py`
- Sử dụng `ilspycmd -p --nested-directories --disable-updatecheck -r <ManagedDir> -o <OutDir> <DLLPath>`.
- Lưu trữ tại `docs/agent-system/evidence/dupery/generated/decompiled_cs/<assembly_name>/`.
- Tạo `docs/agent-system/evidence/dupery/decompile_manifest.json` ghi lại hash SHA256 từng DLL gốc, số lượng file `.cs`, dung lượng tổng và thời gian thực thi.
- Cung cấp cờ `--verify` để tự động kiểm tra lại tính toàn vẹn của thư mục generated mà không cần decompile lại.
- Tuyệt đối tuân thủ ADR-0010 Line Budget: script điều phối phải $< 300$ LOC, không cheat code.
