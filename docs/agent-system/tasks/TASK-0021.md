# TASK-0021: Build Unified Reverse Engineering Graph Query Interface (query_dupery_graph.py)

## Bối Cảnh & Mục Tiêu Kỹ Thuật
Đến cuối Tầng A (TASK-0010 đến TASK-0020), toàn bộ các khía cạnh giải phẫu tĩnh và bán động của tựa game *Dupery* đã được trích xuất hoàn tất vào kho bằng chứng `docs/agent-system/evidence/dupery/`:
- Mã nguồn C# decompile (1.463 tệp, 1.532 types, 100% CIL tokens).
- 12 Scene Hierarchy Trees (5.279 GameObjects, 7.365 MonoBehaviours).
- Dữ liệu ScriptableObjects, 86 đồ thị XNode, 1.908 translation keys.
- Vault tài nguyên: 879 Sprites, 10 Fonts, 752 Textures với SHA-256.
- 54 Materials, 46 Shaders bytecode, 2 VideoClips, Negative Findings (0 Animation/Particle).
- 6 FMOD Banks, 155 FSB5 audio samples, Event Map 50 enums, 62 GUIDs.
- Golden Reference Protocol (9 categories) & Baseline Manifest.
- Runtime Probe Decision (No-Go with live injection, 100% deterministic seed & analytical easing curves).

Mục tiêu của **TASK-0021** là xây dựng **Giao diện Truy vấn Hợp nhất (Unified Query CLI)** `scripts/agent/query_dupery_graph.py` đóng vai trò là "cổng điều phối trung tâm" (One-Stop Hub) cho toàn bộ Tầng B (các Vòng giải phẫu V1–V8).
CLI này cho phép các Agent trong tương lai chỉ cần gõ 1 lệnh để nhận ngay "Công thức nạp context tươi" (**Fresh Context Recipe** per `DEC-19`) gồm đường dẫn code C#, scene JSON, FMOD audio event, và golden reference checklist của bất kỳ đối tượng hay phân hệ nào mà không cần tự lục lọi thủ công trong hàng ngàn tệp dữ liệu.
