# Thư mục Asset Vật Phẩm Đấu Giá (Auction Items Assets)

Thư mục này dùng để lưu trữ toàn bộ các hình ảnh icon / sprite / asset của các vật phẩm mới trong Hòm Bí Ẩn Đấu Giá.

Định dạng khuyến nghị:
- PNG (có nền trong suốt transparent), JPG hoặc WEBP.
- Kích thước chuẩn: 64x64, 128x128 hoặc 256x256 (tự động co giãn theo kích thước ô lưới 1x1, 1x2, 2x2, 2x3, 3x3).

Sau khi đưa asset vào đây, bạn có thể gửi danh sách thông tin vật phẩm (Tên, Phẩm chất, Giá trị, Kích thước WxH, Tên file ảnh) để hệ thống kết nối tự động vào game.
