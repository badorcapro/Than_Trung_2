## 1. Recovery & Session Startup Protocol (MANDATORY)

Upon session start, context reset, or checkpoint recovery:
1. Read `AGENTS.md` and `.agent_scratchpad.md`.
2. Read `docs/agent-system/state/active-task.json` (if present) to locate the active `TASK-XXXX` contract.
3. For milestone onboarding or new session handoff, inspect [HANDOFF.md](HANDOFF.md) and relevant plans in `docs/agent-system/plans/`.
4. Load **only** the active `docs/agent-system/tasks/TASK-XXXX.md` and its explicitly declared `references`. Do not bulk-read.

## 2. Supreme Operational Invariants (Non-Negotiable)

1. **Contract-First Execution**: No production, scene, or test code may be modified without an active `TASK-XXXX.md` in `ready` or `in_progress` status validated by `python scripts/agent/validate_task.py`.
2. **Strict Scope Containment**: Only modify files listed in `in_scope` of the active `TASK-XXXX.md`. Touching files outside `in_scope` is a critical violation blocked by `scripts/agent/check_scope.py`.
3. **Reference Authority Gate**: Treat only `authority: "approved"` and `status: "current"` entries in `docs/agent-system/reference-registry.json` as truth. If a reference is stale or missing, halt and escalate.
4. **Zero Self-Grading & Subagent Peer-Audit (Fail-Closed)**:
   - Never manually write `TASK-XXXX-receipt.json` or edit `status: verified` in `TASK-XXXX.md`.
   - Run an independent Subagent peer-audit (`check_peer_audit.py`) before verification. Transition to `verified` is performed exclusively via `python scripts/agent/run_verify.py --task TASK-XXXX`.
5. **Engine Guard (Godot Windows Invariant)**: **CẤM chạy `godot --headless` trực tiếp trên Windows** trong subagents/scripts tự động (nguy cơ crash/hang ngầm tiến trình). Mọi kiểm thử tự động phải chạy qua Python test harness hoặc `dotnet test`.
6. **Presentation Separation Contract**: Tách biệt 100% giữa Domain Logic (sinh vụ án Knuth DotNetRandom, đồ thị manh mối, solver, giao thức LAN) và Godot Presentation Layer (Nodes, CanvasLayer, Shaders, Catenary2D). Domain logic phải chạy được headless độc lập engine.
7. **Role-Based Line Budgets ([ADR-0010 DEC-AMEND-01](docs/agent-system/decisions/ADR-0010-role-based-configurable-line-budgets.md))**: Giới hạn dòng theo vai trò (`warn: 800 / review: 900 / hard: 1000 LOC`), kèm post-hoc diff guard chặn placeholder truncation.
8. **Failure Discipline**: Tối đa **1 fix attempt** cho mỗi lỗi/test failure. Dừng lại ngay lập tức nếu fix không giải quyết được và giải trình nguyên nhân gốc rễ.

## 3. Progressive Workflow Routing (Agent Skills)

| Task Intent | Skill to Activate (`.agents/skills/`) | Primary Deterministic Gate (`scripts/agent/`) |
| :--- | :--- | :--- |
| Audit workspace, registry, or check budget health | `project-bootstrap` | `python scripts/agent/validate_registry.py --check-context` |
| Decompose stage plan, check impact, author `TASK-XXXX.md` | `plan-task` | `python scripts/agent/validate_task.py --task TASK-XXXX --sync-state` |
| Load selective references and implement `in_scope` changes | `execute-task` | `python scripts/agent/check_scope.py --task TASK-XXXX` |
| Run test suite, peer-audit, generate receipt, mark `verified` | `verify-task` | `python scripts/agent/run_verify.py --task TASK-XXXX` |
| Review architecture, audit designs, or run `/grill-me` | `critical-engagement` | 3-Gate Adversarial Check (`rule_critical_engagement.md`) |
| Execute and report with calibrated `[V]`/`[I]`/`[U]` evidence | `honest-execution` | Evidence-based reporting (`rule_anti_evasion.md`) |
